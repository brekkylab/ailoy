# ailoy for Node

Node bindings for ailoy, built with [napi-rs](https://napi.rs): the same `AgentBuilder`,
`Agent` and registries as the Rust crate, camelCased, with every call that waits returning a
`Promise` and a turn iterated with `for await`.

```js
const { AgentBuilder, registerTool } = require('ailoy-node')

const add = registerTool(
  { name: 'add', description: 'Add two numbers.', parameters: { type: 'object', properties: { a: { type: 'number' }, b: { type: 'number' } } } },
  ({ a, b }) => a + b,
)

const agent = await new AgentBuilder('anthropic/claude-sonnet-5').tool(add).build()
try {
  for await (const { message } of agent.run('What is 2 + 3?')) {
    console.log(message.role, message.contents)
  }
} finally {
  await agent.close()
}
```

Messages, specs and tool descriptions are plain objects, in the JSON shape ailoy stores and
sends; `types.d.ts` spells them out. Bytes — an embedded image — are a `Buffer`.

## cortex, built in

`Console`, `Directory`, `Image`, `HostMount` and the rest of cortex are exported from here
too: they are [cortex-node](../../../cortex/bindings/node)'s classes, linked into this addon
so that an agent can share a console's session.

```js
const { AgentBuilder, Console, Image } = require('ailoy-node')

const console_ = await Console.builder().stdioClient(['cortex-krun']).image(new Image('python:3.12-slim-trixie')).build()
const agent = await new AgentBuilder('anthropic/claude-sonnet-5').shellTool().console(console_).build()
```

They are not the same types as the `cortex-node` package's, since each addon links its own
cortex: build the console from this package.

## Tools

`registerTool(desc, func)` puts a JavaScript function in the registry and hands `desc` back
for `AgentBuilder.tool`. `func` is called with the model's arguments as one object, and may
return its result or a promise of it. A tool that throws or rejects answers the model with
`"error: <message>"` rather than ending the turn. A registered tool does not keep the process
alive by itself.

## Errors

Every error carries a `code`:

| `code` | When |
|---|---|
| `AILOY_ERROR` | anything ailoy reports — a model no provider serves, a tool not registered, an API error |
| `INVALID_ARG` | an object that does not fit, a spent builder, a negative number |
| `TIMED_OUT`, `CONSOLE_BROKEN`, … | a console's failure, with cortex's code, whether from `Console` or inside a turn |

## Building

The crate links cortex with its `mount` feature, which on macOS needs FUSE-T installed —
see cortex's README.

```sh
cd bindings/node
npm install
npm run build        # or build:debug; writes binding.js, binding.d.ts and ailoy.<platform>.node
npm test
```

`binding.js` and `binding.d.ts` are generated by the build; `index.js` and `index.d.ts` wrap
them. The console test at the end of `__test__/index.spec.mjs` needs a console server, named
by `$CORTEX_CONSOLE`; without one it is skipped.
