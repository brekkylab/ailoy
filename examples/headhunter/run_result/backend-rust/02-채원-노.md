제목: Kestrelbank 정산 플랫폼 서버 개발자 (Rust) 포지션 제안

채원 노님, 안녕하세요.

Kestrelbank의 정산 플랫폼 서버 개발자(Rust) 포지션을 소개드리고 싶어 연락드립니다.

Halcyon Systems에서 초당 8만 건 규모의 이벤트를 받는 Rust 게이트웨이를 만들면서 오프셋
관리와 중복 제거 계층을 직접 설계해 재처리 상황에서도 중복이 생기지 않도록 하신 경험을
프로필에서 확인했습니다. Kestrelbank가 지금 이벤트 수집 계층의 재처리를 다시 설계하면서
정확히 이 문제 — 멱등성과 오프셋 관리로 중복 정산을 막는 일 — 를 맡을 사람을 찾고 있어,
채원 노님의 경험과 정확히 맞아떨어진다고 생각했습니다.

포지션은 정산 배치 파이프라인 재작성, 이벤트 수집 계층 재처리 설계, PostgreSQL 파티셔닝
및 읽기 복제 구성을 주요 업무로 합니다. 근무지는 서울 강남구, 주 3일 출근·2일 재택 조건이라
프로필에 남기신 Hybrid in Seoul 희망 조건과도 맞습니다.

관심 있으시면 짧게 통화나 미팅으로 자세한 내용을 안내드리고 싶습니다.
