# 서버 개발자 (Rust) — 정산 플랫폼

## 회사 소개

Kestrelbank는 이커머스·핀테크 사업자에게 정산 인프라를 제공합니다. 하루 처리 건수가
3년 사이 40배가 됐고, 정산 배치가 마감 시간을 넘기는 일이 분기마다 반복되고 있습니다.
이 포지션은 그 배치를 다시 만드는 일을 맡습니다.

## 주요 업무

- 정산 배치 파이프라인 재작성 (현재 Python + Celery, 단일 마감 윈도우 초과)
- 이벤트 수집 계층의 재처리 설계 — 중복 정산이 발생하지 않도록 멱등성과 오프셋 관리
- PostgreSQL 파티셔닝 및 읽기 복제 구성 (정산 테이블이 단일 인스턴스 한계)

## 자격 요건

- Rust로 프로덕션 서비스를 개발하고 운영한 경험
- 백엔드 개발 경력 4년 이상
- 서울 오피스 주 3일 출근 가능

## 우대 사항

- 분산 시스템에서 장애 조치·재시도·멱등성을 직접 설계한 경험
- Kafka 기반 스트리밍 파이프라인 운영 경험
- 정산·결제 도메인 경험

## 근무 조건

- 고용 형태: 정규직
- 근무지: 서울 강남구 (주 3일 출근, 2일 재택)
- 채용 절차: 서류 검토 → 기술 면접 2회 → 팀 미팅
