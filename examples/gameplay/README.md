# Gameplay

An agent plays [OpenTTD](https://www.openttd.org), the open-source Transport Tycoon Deluxe. It runs a transport company, building stations, roads and airports and buying vehicles, while you watch over VNC.

## Running

Rust (from the repository root):

```sh
cargo run --example gameplay
```

Python:

```sh
cd examples/gameplay/python
uv run main.py
```

Node:

```sh
cd examples/gameplay/node
npm install
npm start
```
