Ailoy is an open-source SDK for building AI agents in your own code, in Python, Node.js or Rust. Each agent gets its own Linux microVM as a sandbox, where it can install software, write and run code, and keep files without touching your machine. You set up the sandbox as part of building the agent.

## What agents do with it

With a computer, an agent can do work you didn't write a function for. Each example below is in the repository, in all three languages:

## What Ailoy gives you

- **A sandbox that's already connected**: make one with [virtx](https://virtx.sh/docs/), built by the same team, and pass it to `sandbox(...)`, with no separate account or glue code.
- **Any machine, GPU included**: your own machine, your own server or virtx's cloud, with that machine's GPU usable inside the sandbox.
- **One string to change models**: every model gets the same message format and tools in the style it expects.
- **The CLI you already use**: Claude, GPT and Gemini run on your Claude Code, Codex or Gemini CLI login by default.
- **One library, three languages**: Python and Node.js bind to one Rust core, with the same API.

## Hello world

<Tabs syncKey="lang">

<TabItem label="Python">

```python
import asyncio

from ailoy import AgentBuilder


async def main() -> None:
    agent = await (
        # For openai, use "openai/gpt-6-luna"
        AgentBuilder("anthropic/claude-haiku-5-5")
        .build()
    )

    async for output in agent.run("What is the meaning of hello world?"):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])


asyncio.run(main())
```

</TabItem>
<TabItem label="Node.js">

```js
const { AgentBuilder } = require('@brekkylab/ailoy')

async function main() {
  // For openai, use "openai/gpt-6-luna"
  const agent = await new AgentBuilder('anthropic/claude-haiku-5-5')
    .build()

  for await (const { message } of agent.run('What is the meaning of hello world?')) {
    for (const part of message.contents) {
      if (part.type === 'text') console.log(part.text)
    }
  }

  await agent.close()
}

main()
```

</TabItem>
<TabItem label="Rust">

```rust
use ailoy::{
    agent::AgentBuilder,
    message::{Message, Part, Role},
};
use futures::StreamExt as _;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // For openai, use "openai/gpt-6-luna"
    let mut agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
        .build()
        .await?;

    let query = Message::new(Role::User).with_contents([Part::text("What is the meaning of hello world?")]);
    let mut stream = agent.run(query);
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }

    Ok(())
}
```
