Ailoy is an open-source SDK for building AI agents in Python, Node.js or Rust. You give an agent a model and tools, and optionally a Linux microVM (a sandbox) where it can install software, run code and keep files without touching your machine.

## Your first agent in three steps

1. **[Install Ailoy](/docs/guides/installation/)** for your language, and set up a model with a CLI login or an API key.

2. **[Run the quick start](/docs/guides/quick-start/)**. You build an agent that answers a question, then give it a sandbox and have it draw a chart.

3. **Add what your agent needs.** Pick a task from [Find the right guide](#find-the-right-guide) below.
