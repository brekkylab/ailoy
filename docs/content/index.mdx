Ailoy is an open-source SDK for building AI agents in Python, Node.js or Rust. Each agent can have a Linux microVM of its own, where it installs software, runs code and keeps files without touching your machine.

## What you can build

With a computer of its own, an agent can do work you didn't write a function for. [ailoy.co/examples](https://ailoy.co/examples/) shows each one running:

  <LinkCard title="CAD modeling" description="Writes CadQuery, renders the part from four sides, looks at the renders and fixes it." href="https://ailoy.co/examples/cad/" />

## Before you start

You need Python 3.10+, Node.js 18+ or Rust 1.95+, a machine that can run microVMs (Linux with KVM, Apple silicon or Windows 11), and a CLI login or API key for the model. [Quick start](/docs/guides/quick-start/) runs your first agent, and [Installation](/docs/guides/installation/) walks through each in detail.

## Choose your path
