import { Tabs, TabItem } from '@astrojs/starlight/components';

`AgentBuilder` creates an [`Agent`](/docs/sdk/agent/). Create a builder with a model name, call any of the methods below, then call `build()`. Every method except `build()` returns the builder, so calls can be chained.

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python
from ailoy import AgentBuilder

agent = await (
    AgentBuilder("anthropic/claude-haiku-5-5")
    .instruction("Answer in one sentence.")
    .web_search_tool()
    .build()
)
```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { AgentBuilder } = require('@brekkylab/ailoy')

const agent = await new AgentBuilder('anthropic/claude-haiku-5-5')
  .instruction('Answer in one sentence.')
  .webSearchTool()
  .build()
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::agent::AgentBuilder;

let agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
    .instruction("Answer in one sentence.")
    .web_search_tool(vec![])
    .build()
    .await?;
```

</TabItem>
</Tabs>

:::note
In Python and Node.js, the builder is changed in place, and `build()` empties it. Create a new builder for each agent.
:::

| Method | Does |
| --- | --- |
| [Constructor](#constructor) | Starts a builder for a model. |
| [`instruction`](#instruction) | Sets the system prompt. |
| [`tool`](#tool), [`tools`](#tools) | Add tools by their description. |
| [`web_search_tool`](#web_search_tool) | Adds `web_search`. |
| [`web_fetch_tool`](#web_fetch_tool) | Adds `web_fetch`. |
| [`sandbox`](#sandbox) | Gives the agent a sandbox and the shell and file tools. |
| [`browser`](#browser) | Gives the agent a browser and the `browser_*` tools. |
| [`skill`](#skill) | Adds a skill from a folder in the sandbox. |
| [`memory`](#memory) | Lets the agent keep notes on the user. |
| [`context_manager`](#context_manager) | Keeps the history under the model's limits. |
| [`thinking_effort`](#thinking_effort) | Sets how much the model reasons. |
| [`output_schema`](#output_schema) | Makes answers match a JSON schema. |
| [`history`](#history) | Starts from a saved conversation. |
| [`build`](#build) | Creates the agent. |

## browser

Gives the agent `browser_*` tools that control a Chromium-based browser over CDP. See [Use a browser](/docs/guides/using-browser/).

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python
.browser(
    *,
    user_browser: str | Path | None = None,
    careful: bool = True,
    start_url: str | None = None,
    isolated: bool = False,
    headless: bool = False,
    executable: str | Path | None = None,
    profile: str | Path | None = None,
) -> AgentBuilder
```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
.browser(options?: {
  userBrowser?: 'chrome' | 'chrome-beta' | 'chrome-dev' | 'chrome-canary' | 'chromium' | 'edge' | 'brave' | { userDataDir: string },
  careful?: boolean,
  startUrl?: string,
  isolated?: boolean,
  headless?: boolean,
  executable?: string,
  profile?: string,
}): AgentBuilder
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::browser::{Browser, UserBrowser};

.browser(browser: Browser) -> AgentBuilder

// Your own browser, or a separate one:
Browser::user()
Browser::isolated()
// Options, each returning the Browser:
.user_browser(UserBrowser)   // Chrome, ChromeBeta, ChromeDev, ChromeCanary, Chromium, Edge, Brave, Custom(PathBuf)
.careful(bool)
.start_url(impl Into<String>)
.headless(bool)
.executable(impl Into<PathBuf>)
.profile(impl Into<PathBuf>)
```

</TabItem>
</Tabs>

| Option | Type | Default | Applies to | Description |
| --- | --- | --- | --- | --- |
| `isolated` | bool | `false` | | `false` uses your own browser. `true` starts a separate browser on first use and closes it with the agent. |
| `user_browser` | string or path | The browser that turned on remote debugging most recently | Your own browser | `"chrome"`, `"chrome-beta"`, `"chrome-dev"`, `"chrome-canary"`, `"chromium"`, `"edge"`, `"brave"`, or the user data directory of any other Chromium-based browser. |
| `careful` | bool | `true` | Both | Tells the agent to use sites as a person would, so bot checks are less likely to block it. |
| `start_url` | string | | Both | The page the agent's tab opens on. |
| `headless` | bool | `false` | Separate browser | Runs without a window. |
| `executable` | path | The first of Chrome, Chromium, Edge or Brave found | Separate browser | The browser executable to start. |
| `profile` | path | A fresh profile, deleted afterwards | Separate browser | A user data directory to keep, so sign-ins last between runs. |

Mixing options for your own browser with options for a separate browser fails at `build()`.

**Example**

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python

```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const agent = await new AgentBuilder('anthropic/claude-sonnet-5-5').browser({ isolated: true }).build()
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::browser::Browser;

let agent = AgentBuilder::new("anthropic/claude-sonnet-5-5").browser(Browser::isolated()).build().await?;
```

</TabItem>

## context_manager

Limits how much old tool output and how many old images the history keeps. Node.js: `contextManager`. See [Manage context](/docs/guides/context-manager/).

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python
.context_manager(
    max_input_tokens: int | None = None,
    preserve_recent_turns: int | None = None,
    max_images: int | None = None,
    preserve_recent_images: int | None = None,
) -> AgentBuilder
```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
.contextManager(options?: {
  maxInputTokens?: number,
  preserveRecentTurns?: number,
  maxImages?: number,
  preserveRecentImages?: number,
}): AgentBuilder
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::agent::ContextManager;

.context_manager(spec: ContextManager) -> AgentBuilder
// ContextManager { max_input_tokens: 50_000, ..Default::default() }
```

</TabItem>
</Tabs>

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `max_input_tokens` | int | `0` (off) | Input size in tokens above which old tool results are replaced. |
| `preserve_recent_turns` | int | `3` | How many recent turns are never changed. |
| `max_images` | int | `30` | How many tool-result images the history can hold. `0` turns the cap off. |
| `preserve_recent_images` | int | `10` | How many tool-result images are kept once the cap is reached. |

Without this call, the agent uses these defaults.

**Example**

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python
agent = await (
    AgentBuilder("anthropic/claude-haiku-5-5")
    .context_manager(max_input_tokens=50_000, preserve_recent_turns=2)
    .build()
)
```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const agent = await new AgentBuilder('anthropic/claude-haiku-5-5')
  .contextManager({ maxInputTokens: 50000, preserveRecentTurns: 2 })
  .build()
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::agent::ContextManager;

let agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
    .context_manager(ContextManager { max_input_tokens: 50_000, preserve_recent_turns: 2, ..Default::default() })
```

## build

Builds the agent. This is when the model is created, API keys are read from the environment, and skills are read from the sandbox.

<Tabs syncKey="lang">
<TabItem label="Python" icon="seti:python">

```python
async def build() -> Agent
```

</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
build(): Promise<Agent>
```

</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
async fn build(self) -> anyhow::Result<Agent>
```

</TabItem>
</Tabs>

**Returns** the [`Agent`](/docs/sdk/agent/). In Python and Node.js, the builder is emptied.

**Raises** if the org has no backend, a required API key is missing, a skill's `SKILL.md` is missing or invalid, or the browser options conflict. Calling `build()` a second time on the same builder raises `ValueError` in Python and an `INVALID_ARG` error in Node.js. See [Errors](/docs/sdk/errors/).
