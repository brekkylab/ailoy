Build your first agent in two steps: one that answers a question, then the same agent with a sandbox where it writes and runs code.

:::note[Before you start]
Finish [Installation](/docs/guides/installation/) first: install the package and set up a model. The code below uses `anthropic/claude-haiku-5-5` through Claude Code. To use GPT instead, change the model to `openai/gpt-6-luna`.
:::

## Run an agent

The smallest agent is a model and nothing else. It has no tools, so it answers from what the model knows.

Save this code as `main.py` (Python), `main.js` (Node.js) or `src/main.rs` (Rust):

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
import asyncio

from ailoy import AgentBuilder


async def main() -> None:
    agent = await (
        # For openai, use "openai/gpt-6-luna"
        AgentBuilder("anthropic/claude-haiku-5-5")
        .build()
    )

    async for output in agent.run("What is the meaning of hello world?"):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])


asyncio.run(main())
```

</TabItem>

<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{
    agent::AgentBuilder,
    message::{Message, Part, Role},
};
use futures::StreamExt as _;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // For openai, use "openai/gpt-6-luna"
    let mut agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
        .build()
        .await?;

    let query = Message::new(Role::User).with_contents([Part::text("What is the meaning of hello world?")]);
    let mut stream = agent.run(query);
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }

    Ok(())
}
```

## Give it a sandbox

Now give the same agent a sandbox: a Linux microVM where it can install software, write and run code, and save files, without touching your machine. Your machine must meet the [sandbox requirements](/docs/guides/installation/#check-the-requirements).

Replace your file with the code below. The highlighted lines are new. They:

1. Start the sandbox server (downloaded the first time, so the first run takes longer).
2. Create a sandbox from the `python:3.12-slim-trixie` image.
3. Pass the sandbox to the agent with `.sandbox(sandbox)`.
4. Copy the chart the agent makes out of the sandbox to `population.png` on your machine.

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python ins={2,5,9-13,18-19,28} mark={23}
import asyncio
from pathlib import Path

from ailoy import AgentBuilder
from virtx import Client


async def main() -> None:
    # Starts virtx's server, fetched into its cache the first time.
    client = Client.spawn()
    await client.pull_image("python:3.12-slim-trixie").complete()
    sandbox = await client.create_sandbox("python:3.12-slim-trixie")

    agent = await (
        # For openai, use "openai/gpt-6-luna"
        AgentBuilder("anthropic/claude-haiku-5-5")
        .instruction("Write what you are asked for into /artifacts.")
        .sandbox(sandbox)
        .build()
    )

    async for output in agent.run("Create a bar chart comparing the populations of European countries and save it to /artifacts/population.png."):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])

    Path("population.png").write_bytes(await sandbox.read_file("artifacts/population.png"))

asyncio.run(main())
```

</TabItem>

const { writeFileSync } = require('node:fs')
const { AgentBuilder } = require('@brekkylab/ailoy')
const { Client } = require('@brekkylab/virtx')

async function main() {
  // Starts virtx's server, fetched into its cache the first time.
  const client = Client.spawn()
  await client.pullImage('python:3.12-slim-trixie').complete()
  const sandbox = await client.createSandbox('python:3.12-slim-trixie')

  // For openai, use "openai/gpt-6-luna"
  const agent = await new AgentBuilder('anthropic/claude-haiku-5-5')
    .instruction('Write what you are asked for into /artifacts.')
    .sandbox(sandbox)
    .build()

  for await (const { message } of agent.run('Create a bar chart comparing the populations of European countries and save it to /artifacts/population.png.')) {
    for (const part of message.contents) {
      if (part.type === 'text') console.log(part.text)
    }
  }

  writeFileSync('population.png', await sandbox.readFile('artifacts/population.png'))
  await agent.close()
  await client.close()
}

main()

<TabItem label="Rust" icon="seti:rust">

```rust ins={6,10-18,22-23,38-39} mark={27}
use ailoy::{
    agent::AgentBuilder,
    message::{Message, Part, Role},
};
use futures::StreamExt as _;
use virtx::{Client, Files as _, SandboxCreateArgs};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Starts virtx's server, fetched into its cache the first time.
    let client = Client::spawn_virtx([] as [&str; 0]).await?;
    client.pull_image("python:3.12-slim-trixie", None).complete(false).await?;
    let sandbox = client
        .create_sandbox(&SandboxCreateArgs::new("python:3.12-slim-trixie"))
        .await?;

    // For openai, use "openai/gpt-6-luna"
    let mut agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
        .instruction("Write what you are asked for into /artifacts.")
        .sandbox(sandbox.clone())
        .build()
        .await?;

    let query = Message::new(Role::User).with_contents([Part::text("Create a bar chart comparing the populations of European countries and save it to /artifacts/population.png.")]);
    let mut stream = agent.run(query);
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }

    let png = sandbox.read_file("artifacts/population.png", 0, None).await?;
    std::fs::write("population.png", png)?;
    Ok(())
}
```

## What happened

The Python image doesn't include matplotlib, so the agent installs it with the shell tool that `.sandbox(sandbox)` gives it, then writes and runs code that saves the chart to `/artifacts`. Each of those actions is a tool call: the model asks for it, and Ailoy runs it inside the sandbox and sends the result back to the model. When the agent finishes, your code copies the chart out of the sandbox.
