An agent can use the tools of any [MCP](https://modelcontextprotocol.io) server. It takes two steps:

1. Register the server with a prefix. You get back a description of each of its tools.
2. Pass those descriptions to the `AgentBuilder` with `.tools(...)`.

Each tool is registered as `<prefix>__<name>`, so tools from different servers don't clash. For example, the `fetch` tool of a server registered with the prefix `fetch` becomes `fetch__fetch`.

## Connect a local (stdio) server

`register_mcp_stdio` starts the server as a process on your machine and talks to it over stdin and stdout. This example runs [`mcp-server-fetch`](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch) with `uvx`:

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
import asyncio

from ailoy import AgentBuilder, register_mcp_stdio


async def main() -> None:
    tools = await register_mcp_stdio("fetch", "uvx", ["mcp-server-fetch"])

    agent = await (
        AgentBuilder("anthropic/claude-haiku-5-5")
        .tools(tools)
        .build()
    )

    async for output in agent.run("Summarize https://modelcontextprotocol.io in three sentences."):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])


asyncio.run(main())
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { AgentBuilder, registerMcpStdio } = require('@brekkylab/ailoy')

async function main() {
  const tools = await registerMcpStdio('fetch', 'uvx', ['mcp-server-fetch'])

  const agent = await new AgentBuilder('anthropic/claude-haiku-5-5')
    .tools(tools)
    .build()

  try {
    for await (const { message } of agent.run('Summarize https://modelcontextprotocol.io in three sentences.')) {
      for (const part of message.contents) {
        if (part.type === 'text') console.log(part.text)
      }
    }
  } finally {
    await agent.close()
  }
}

main()
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{
    agent::AgentBuilder,
    message::{Message, Part, Role},
    tool::register_mcp_stdio,
};
use futures::StreamExt as _;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let tools = register_mcp_stdio("fetch", "uvx", ["mcp-server-fetch"]).await?;

    let mut agent = AgentBuilder::new("anthropic/claude-haiku-5-5")
        .tools(tools)
        .build()
        .await?;

    let query = Message::new(Role::User)
        .with_contents([Part::text("Summarize https://modelcontextprotocol.io in three sentences.")]);
    let mut stream = agent.run(query);
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }
    Ok(())
}
```


</TabItem>
</Tabs>

:::caution
A stdio server runs on your machine, not in the agent's sandbox, with the same access as your program. Only register servers you trust.
:::

## Connect a remote (HTTP) server

`register_mcp_streamable_http` connects to a remote server by URL, using the Streamable HTTP transport. This example connects [DeepWiki](https://deepwiki.com)'s server, which answers questions about GitHub repositories:

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
from ailoy import register_mcp_streamable_http

tools = await register_mcp_streamable_http("deepwiki", "https://mcp.deepwiki.com/mcp")
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { registerMcpStreamableHttp } = require('@brekkylab/ailoy')

const tools = await registerMcpStreamableHttp('deepwiki', 'https://mcp.deepwiki.com/mcp')
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::tool::register_mcp_streamable_http;

let tools = register_mcp_streamable_http("deepwiki", "https://mcp.deepwiki.com/mcp").await?;
```


</TabItem>
</Tabs>

Then pass `tools` to `.tools(...)` on the builder, as in the first example.

## Disconnect a server

`unregister_mcp` (`unregisterMcp` in Node.js) removes all the tools registered with a prefix and closes the connection to the server.

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
from ailoy import unregister_mcp

unregister_mcp("fetch")
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { unregisterMcp } = require('@brekkylab/ailoy')

unregisterMcp('fetch')
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
ailoy::tool::unregister_mcp("fetch");
```


</TabItem>
</Tabs>

## Troubleshooting

| Error | Cause and fix |
| --- | --- |
| `No such file or directory (os error 2)` or `program not found` from `register_mcp_stdio` | The command, such as `uvx`, isn't installed or isn't on your program's `PATH`. Install it (`uvx` comes with [uv](https://docs.astral.sh/uv/)), or pass its full path. |
| `connection closed: initialize response` | The server started and exited before it answered. Its error output isn't shown, so run the same command in a terminal to see why. |
| A tool's name differs from the server's name for it | Tools are named `<prefix>__<name>`, and any character other than letters, digits, `_` and `-` becomes `_`. For example, prefix `my.server` and tool `odd/name` give `my_server__odd_name`. Names over 64 characters log a warning, because some model APIs reject them. |
