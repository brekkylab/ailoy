An agent can use the tools of any [MCP](https://modelcontextprotocol.io) server. Register the server, and you get back the names of its tools. List those in the agent's spec, under `tools`.

Each tool is registered as `{prefix}__{name}`, so tools from different servers don't clash. For example, the `fetch` tool of a server registered under `fetch` becomes `fetch__fetch`.

## Stdio servers

`register_mcp_stdio` (`registerMcpStdio` in Node.js, `MCPTransport::Stdio` in Rust) starts the server as a local process and talks to it over stdin and stdout. This runs [`mcp-server-fetch`](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch) with `uvx`:

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
import asyncio

from ailoy import Agent, register_mcp_stdio


async def main() -> None:
    tools = await register_mcp_stdio("fetch", "uvx", ["mcp-server-fetch"])

    agent = await Agent.from_spec({"model": "anthropic/claude-haiku-5-5", "tools": tools})

    async for output in agent.run("Summarize https://modelcontextprotocol.io in three sentences."):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])

    await agent.close()


asyncio.run(main())
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { Agent, registerMcpStdio } = require('@brekkylab/ailoy')

async function main() {
  const tools = await registerMcpStdio('fetch', 'uvx', ['mcp-server-fetch'])

  const agent = await Agent.fromSpec({ model: 'anthropic/claude-haiku-5-5', tools })

  try {
    for await (const { message } of agent.run('Summarize https://modelcontextprotocol.io in three sentences.')) {
      for (const part of message.contents) {
        if (part.type === 'text') console.log(part.text)
      }
    }
  } finally {
    await agent.close()
  }
}

main()
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{
    Agent,
    agent::{AgentSpec, default_provider},
    message::{Message, Part, Role},
    tool::{MCPServer, MCPTransport},
};
use futures::StreamExt as _;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let transport = MCPTransport::Stdio {
        command: "uvx".into(),
        args: vec!["mcp-server-fetch".into()],
    };
    let server = MCPServer::connect("fetch", transport).await?;
    let tools = default_provider().write().unwrap().tools.set(server);

    let spec = AgentSpec::new("anthropic/claude-haiku-5-5").tools(tools);
    let agent = Agent::from_spec(spec, Vec::new(), None).await?;

    let query = Message::new(Role::User)
        .with_contents([Part::text("Summarize https://modelcontextprotocol.io in three sentences.")]);
    let mut stream = std::pin::pin!(agent.run(&query));
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }
    agent.close().await?;
    Ok(())
}
```


</TabItem>
</Tabs>

:::caution
A stdio server runs on the host, not in the agent's sandbox, with the same access as your program. Register only servers you trust.
:::

## Streamable HTTP servers

`register_mcp_streamable_http` (`registerMcpStreamableHttp`, `MCPTransport::StreamableHTTP`) connects to a remote server by its URL. This registers [DeepWiki](https://deepwiki.com)'s server, which answers questions about GitHub repositories:

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
from ailoy import register_mcp_streamable_http

tools = await register_mcp_streamable_http("deepwiki", "https://mcp.deepwiki.com/mcp")
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { registerMcpStreamableHttp } = require('@brekkylab/ailoy')

const tools = await registerMcpStreamableHttp('deepwiki', 'https://mcp.deepwiki.com/mcp')
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{
    agent::default_provider,
    tool::{MCPServer, MCPTransport},
};

let transport = MCPTransport::StreamableHTTP { url: "https://mcp.deepwiki.com/mcp".into() };
let server = MCPServer::connect("deepwiki", transport).await?;
let tools = default_provider().write().unwrap().tools.set(server);
```


</TabItem>

List `tools` in the agent's spec as above.

## Unregistering

`unregister_mcp` (`unregisterMcp` in Node.js) removes a server's tools by their prefix and closes the connection to the server. In Rust, `remove_by_prefix` on the provider's `tools` does the same, with the prefix as `MCPServer::name_prefix` spells it; the connection closes once none of the server's tools is left.

<Tabs syncKey="lang">

<TabItem label="Python" icon="seti:python">

```python
from ailoy import unregister_mcp

unregister_mcp("fetch")
```


</TabItem>
<TabItem label="Node.js" icon="seti:javascript">

```js
const { unregisterMcp } = require('@brekkylab/ailoy')

unregisterMcp('fetch')
```


</TabItem>
<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{agent::default_provider, tool::MCPServer};

default_provider().write().unwrap().tools.remove_by_prefix(&MCPServer::name_prefix("fetch"));
```


</TabItem>

## Troubleshooting

| What you see | Why, and what to do |
| --- | --- |
| An OS error such as `No such file or directory (os error 2)` or `program not found` from `register_mcp_stdio` or `MCPServer::connect` | The command, such as `uvx`, isn't installed or isn't on your program's `PATH`. Install it (`uvx` comes with [uv](https://docs.astral.sh/uv/)), or give its full path. |
| `connection closed: initialize response` | The server started and exited before answering. Its error output isn't shown, so run the same command in a terminal to see why. |
| A tool's name isn't the one the server gives it | Tools are named `<prefix>__<name>`, and any character outside letters, digits, `_` and `-` becomes `_`: prefix `my.server` and tool `odd/name` give `my_server__odd_name`. A name over 64 characters logs a warning, since some model APIs refuse it. |
