An agent's browser is in its [sandbox](/docs/guides/sandbox/): virtx's `browser` abin, a headless Chromium driven by [agent-browser](https://github.com/vercel-labs/agent-browser). Set `use_browser` in the spec beside `use_sandbox`, and have the sandbox made with that abin; the agent gets the `browser` and `browser_screenshot` tools. The sandbox needs a network for pages outside it, and 2 GiB or more of memory, since Chromium takes a few hundred megabytes.

```python
import asyncio

import ailoy
from ailoy import Agent
from virtx import Client


async def main() -> None:
    client = Client.spawn()
    await client.pull_image("python:3.12-slim-trixie").complete()
    ailoy.set_virtx(client)

    agent = await Agent.from_spec(
        {
            "model": "anthropic/claude-sonnet-5-5",
            "use_sandbox": True,
            "use_browser": True,
        },
        sandbox={
            "create": {
                "image": {"type": "tag", "tag": "python:3.12-slim-trixie"},
                "network": True,
                "memory_mib": 2048,
                "abins": ["browser"],
            }
        },
    )
    async for output in agent.run("Open https://example.com and tell me its title."):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])

    await agent.close()


asyncio.run(main())
```

```js
const { Agent, setVirtx } = require('@brekkylab/ailoy')
const { Client } = require('@brekkylab/virtx')

async function main() {
  const client = Client.spawn()
  await client.pullImage('python:3.12-slim-trixie').complete()
  setVirtx(client)

  const agent = await Agent.fromSpec(
    {
      model: 'anthropic/claude-sonnet-5-5',
      use_sandbox: true,
      use_browser: true,
    },
    {
      sandbox: {
        create: {
          image: { type: 'tag', tag: 'python:3.12-slim-trixie' },
          network: true,
          memory_mib: 2048,
          abins: ['browser'],
        },
      },
    },
  )
  try {
    for await (const { message } of agent.run('Open https://example.com and tell me its title.')) {
      for (const part of message.contents) {
        if (part.type === 'text') console.log(part.text)
      }
    }
  } finally {
    await agent.close()
  }
}

main()
```

<TabItem label="Rust" icon="seti:rust">

```rust
use ailoy::{
    Agent,
    agent::{AgentSpec, SessionSandbox, default_provider},
    message::{Message, Part, Role},
};
use futures::StreamExt as _;
use virtx::{Client, SandboxCreateArgs};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let client = Client::spawn_virtx([] as [&str; 0]).await?;
    client.pull_image("python:3.12-slim-trixie", None).complete(false).await?;
    default_provider().write().unwrap().virtx = Some(client.clone());

    let spec = AgentSpec::new("anthropic/claude-sonnet-5-5").sandbox().browser();
    let sandbox = SessionSandbox::Create(
        SandboxCreateArgs::new("python:3.12-slim-trixie")
            .network(true)
            .memory_mib(2048)
            .abin("browser"),
    );
    let agent = Agent::from_spec(spec, Vec::new(), Some(sandbox)).await?;

    let query = Message::new(Role::User)
        .with_contents([Part::text("Open https://example.com and tell me its title.")]);
    let mut stream = std::pin::pin!(agent.run(&query));
    while let Some(output) = stream.next().await {
        let message = output?.message;
        if message.role == Role::Assistant {
            for text in message.contents.iter().filter_map(Part::as_text) {
                println!("{text}");
            }
        }
    }

    agent.close().await?;
    Ok(())
}
```

Making the agent fails when its spec has `use_browser` without `use_sandbox`, or its sandbox is made without the `browser` abin. In Rust, `AgentSpec`'s `sandbox()` and `browser()` set the two. Closing the agent removes its sandbox, and the browser with it.

## The tools

| Tool | What it does |
|---|---|
| `browser` | Runs one of the abin's commands, given as a list of arguments: `["open", "https://example.com"]`, `["snapshot", "-i"]`, `["click", "@e3"]`, `["fill", "@e2", "text"]`. It answers as `shell` does, with the command's output and exit code. |
| `browser_screenshot` | The current page as an image, with `full` for its whole height and `annotate` to label each element with its ref. |

What the commands are is in the abin's `SKILL.md`, which Ailoy lists in the system message as it does every abin's (see [Skills](/docs/guides/skills/)). In short, the agent opens a page, takes a snapshot, the page's accessibility tree with a ref such as `@e3` on what it can act on, acts on a ref, and takes a snapshot again after the page changes.

Every command uses the same browser, with its tabs, cookies and refs, for as long as the sandbox's machine is up. A machine nothing runs in is parked after a few minutes, and the browser goes with it: the next command answers as a new browser would. The abin's own `state save` and `--state` keep a sign-in past that.

Screenshots count toward the images the history keeps, as in [Images past the cap](/docs/guides/truncation/#images-past-the-cap).
