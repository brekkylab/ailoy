An agent's browser is in its [sandbox](/docs/guides/sandbox/): virtx's `browser` abin, a headless Chromium driven by [agent-browser](https://github.com/vercel-labs/agent-browser). Make the sandbox with that abin and call `browser()` on the `AgentBuilder`; the agent gets the `browser` and `browser_screenshot` tools. The sandbox needs a network for pages outside it, and 2 GiB or more of memory, since Chromium takes a few hundred megabytes.

<TabItem label="Python" icon="seti:python">

```python
import asyncio

from ailoy import AgentBuilder
from virtx import Client


async def main() -> None:
    client = Client.spawn()
    await client.pull_image("python:3.12-slim").complete()
    sandbox = await client.create_sandbox(
        "python:3.12-slim", network=True, abins=["browser"], memory_mib=2048
    )

    agent = await (
        AgentBuilder("anthropic/claude-sonnet-5-5").sandbox(sandbox).browser().build()
    )
    async for output in agent.run("Open https://example.com and tell me its title."):
        for part in output["message"]["contents"]:
            if part["type"] == "text":
                print(part["text"])

    await agent.close()
    await sandbox.remove()


asyncio.run(main())
```

```js
const { AgentBuilder } = require('@brekkylab/ailoy')
const { Client } = require('@brekkylab/virtx')

async function main() {
  const client = Client.spawn()
  await client.pullImage('python:3.12-slim').complete()
  const sandbox = await client.createSandbox('python:3.12-slim', {
    network: true,
    abins: ['browser'],
    memoryMib: 2048,
  })

  const agent = await new AgentBuilder('anthropic/claude-sonnet-5-5').sandbox(sandbox).browser().build()
  try {
    for await (const { message } of agent.run('Open https://example.com and tell me its title.')) {
      for (const part of message.contents) {
        if (part.type === 'text') console.log(part.text)
      }
    }
  } finally {
    await agent.close()
    await sandbox.remove()
  }
}

main()
```

Building the agent fails when it has no sandbox, or a sandbox without the `browser` abin. In a spec, `browser()` is `use_browser`.

## The tools

| Tool | What it does |
|---|---|
| `browser` | Runs one of the abin's commands, given as a list of arguments: `["open", "https://example.com"]`, `["snapshot", "-i"]`, `["click", "@e3"]`, `["fill", "@e2", "text"]`. It answers as `shell` does, with the command's output and exit code. |
| `browser_screenshot` | The current page as an image, with `full` for its whole height and `annotate` to label each element with its ref. |

What the commands are is in the abin's `SKILL.md`, which Ailoy lists in the system message as it does every abin's (see [Skills](/docs/guides/skills/)). In short, the agent opens a page, takes a snapshot, the page's accessibility tree with a ref such as `@e3` on what it can act on, acts on a ref, and takes a snapshot again after the page changes.

Every command uses the same browser, with its tabs, cookies and refs, for as long as the sandbox's machine is up. A machine nothing runs in is parked after a few minutes, and the browser goes with it: the next command answers as a new browser would. The abin's own `state save` and `--state` keep a sign-in past that.

Screenshots count toward the images the history keeps, as in [Images past the cap](/docs/guides/truncation/#images-past-the-cap).
