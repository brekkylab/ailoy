The computer an agent works on is a Linux VM run by [virtx](https://github.com/brekkylab/virtx). Ailoy depends on virtx, and your code uses it directly:

- **Python:** the `virtx` package (`import virtx`), which `pip install ailoy-py` installs too
- **Node.js:** `@brekkylab/virtx` (`npm install @brekkylab/virtx` beside `@brekkylab/ailoy`)
- **Rust:** the `virtx` crate (`ailoy::console::Sandbox` is the same type as `virtx::Sandbox`)

A `Client` reaches virtx's server. `Client.spawn()` (`Client::spawn_virtx` in Rust) starts one on your machine, fetched into virtx's cache the first time. Through the client you build images, make volumes, and make the sandbox the agent works in:

- An **image** is the VM's disk: a base image plus setup steps, much like a Dockerfile.
- A **sandbox** is a VM booted from an image. It runs commands and holds files, and it is what the agent gets.
- A **volume** is a folder kept on the server, mounted into a sandbox. It is how files go in before a run and come out after.

A `Sandbox` is handed to `AgentBuilder.sandbox` as is, and the agent's tools run in it over the same client. The sandbox stays yours:

- Closing the agent leaves the sandbox as it is; `remove()` removes it, and the agent's next command then fails.
- A sandbox runs many processes at once, so your own commands in it run beside the agent's.

## Images

A `Recipe` is a base image plus steps. `build_image` builds it and stores it under a name, so a sandbox can boot from it later without building it again; iterating what it returns follows the build's log, and its last entry says whether it failed. `pull_image` stores an image from a registry as it is.

<Tabs syncKey="lang">

<TabItem label="Python">

```python
import asyncio

from virtx import Client, ImageJobEnd, Recipe


async def main() -> None:
    # Starts virtx's server, fetched into its cache the first time.
    client = Client.spawn()

    recipe = Recipe("python:3.12-slim-trixie").run("pip install matplotlib")
    async for entry in client.build_image(recipe, "plot:latest"):
        if isinstance(entry.entry, ImageJobEnd) and entry.entry.error:
            raise RuntimeError(entry.entry.error)

    for image in await client.list_image():
        print(image.reference)


asyncio.run(main())
```


</TabItem>
<TabItem label="Node.js">

```js
const { Client, Recipe } = require('@brekkylab/virtx')

async function main() {
  // Starts virtx's server, fetched into its cache the first time.
  const client = Client.spawn()
  try {
    const recipe = new Recipe('python:3.12-slim-trixie').run('pip install matplotlib')
    for await (const entry of client.buildImage(recipe, 'plot:latest')) {
      if ('end' in entry && entry.end.error) throw new Error(entry.end.error)
    }

    for (const image of await client.listImage()) {
      console.log(image.reference)
    }
  } finally {
    await client.close()
  }
}

main()
```


</TabItem>
<TabItem label="Rust">

```rust
use futures::StreamExt as _;
use virtx::{Client, ImageJobEntry, Recipe};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Starts virtx's server, fetched into its cache the first time.
    let client = Client::spawn_virtx([] as [&str; 0])?;

    let recipe = Recipe::new("python:3.12-slim-trixie").step("pip install matplotlib");
    let mut log = client.build_image(recipe, "plot:latest").log();
    while let Some(entry) = log.next().await {
        if let ImageJobEntry::End(end) = entry?.entry
            && let Some(error) = end.error
        {
            anyhow::bail!(error);
        }
    }

    for image in client.list_image().await? {
        println!("{}", image.reference);
    }
    Ok(())
}
```

The server answers a reference in its full form, as `docker.io/library/plot:latest`. Once no sandbox boots from an image, `remove_image("plot:latest")` (`removeImage` in Node.js) removes it.

### From a shell

The `virtx` command builds and manages the same images from a shell, with `docker`'s spelling. The virtx packages install it, so a project that installed Ailoy has it: `pip install ailoy-py` puts it in the environment's `bin/`, and `@brekkylab/virtx` in `node_modules/.bin`. Without installing anything:

```bash
uvx virtx --help
npx @brekkylab/virtx --help
```

```bash
virtx build -t plot:latest .                         # ./Dockerfile
virtx build -t plot:latest - <<'EOF'                 # a Dockerfile from stdin
FROM python:3.12-slim-trixie
RUN pip install matplotlib
EOF
virtx images                                         # one line per ref, with its image ID
virtx inspect plot:latest                            # its digest and refs, as JSON
virtx tag plot:latest plot:v1                        # another ref on the same image
virtx rmi plot:v1                                    # by ref, image ID or digest
virtx pull alpine:3.20                               # a base from a registry, as it is named
virtx save -o plot.tar plot:latest                   # to an OCI archive; `virtx load` reads one back
```

`virtx <COMMAND> --help` says what each command takes, and each is also an `image` command, as in `docker` (`virtx image ls`, `virtx image rm`, `virtx image prune`). It starts the same server a client does; `--host URL` reaches one over HTTP instead. Ctrl-C during a build or pull cancels it.

## Sandboxes

`create_sandbox` (`createSandbox` in Node.js) boots a sandbox from an image. What it takes besides the image is optional: `network` (on unless set to false), `vcpus`, `memory_mib`, `gpu`, `ports` to open, and `volumes` to mount. `exec` runs a command in it, and iterating what it returns follows the command's output, line by line, to how it ended. The sandbox's own files are read and written by path from its root, as `artifacts/population.png`.

<Tabs syncKey="lang">

<TabItem label="Python">

```python
import asyncio

from virtx import Client, Stdout


async def main() -> None:
    client = Client.spawn()
    sandbox = await client.create_sandbox("plot:latest", vcpus=2, memory_mib=2048)

    async for entry in sandbox.exec(["python", "-c", "import matplotlib; print(matplotlib.__version__)"]):
        if isinstance(entry.entry, Stdout):
            print(entry.entry.line)

    print(await sandbox.read_text("etc/hostname"), end="")
    await sandbox.remove()


asyncio.run(main())
```


</TabItem>
<TabItem label="Node.js">

```js
const { Client } = require('@brekkylab/virtx')

async function main() {
  const client = Client.spawn()
  try {
    const sandbox = await client.createSandbox('plot:latest', { vcpus: 2, memoryMib: 2048 })

    for await (const entry of sandbox.exec(['python', '-c', 'import matplotlib; print(matplotlib.__version__)'])) {
      if ('stdout' in entry) console.log(entry.stdout)
    }

    process.stdout.write(await sandbox.readText('etc/hostname'))
    await sandbox.remove()
  } finally {
    await client.close()
  }
}

main()
```


</TabItem>
<TabItem label="Rust">

```rust
use futures::StreamExt as _;
use virtx::{Client, Files as _, SandboxCreateArgs, SandboxExecArgs, SandboxJobEntry};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let client = Client::spawn_virtx([] as [&str; 0])?;
    let sandbox = client
        .create_sandbox(&SandboxCreateArgs::new("plot:latest").vcpus(2).memory_mib(2048))
        .await?;

    let cmd = ["python", "-c", "import matplotlib; print(matplotlib.__version__)"];
    let mut log = sandbox.exec(&SandboxExecArgs::new(cmd)).log();
    while let Some(entry) = log.next().await {
        if let SandboxJobEntry::Stdout(line) = entry?.entry {
            println!("{line}");
        }
    }

    print!("{}", sandbox.read_text("etc/hostname").await?);
    sandbox.remove().await?;
    Ok(())
}
```

The sandboxes a spawned server holds go with it, when its client is closed or your program ends.

## Volumes

A volume is made once and kept on the server, across sandboxes and runs; making one by a name already there is refused with a `409`, and `get_volume` (`getVolume`) answers the one there. Write files onto it, mount it into a sandbox, read-only or not, and read what the sandbox wrote back from it after.

<Tabs syncKey="lang">

<TabItem label="Python">

```python
from pathlib import Path

from virtx import SandboxVolume

data = await client.create_volume("plot-data")
await data.write_file("populations.csv", Path("populations.csv").read_bytes())
artifacts = await client.create_volume("plot-artifacts")

sandbox = await client.create_sandbox(
    "plot:latest",
    volumes=[
        SandboxVolume(volume=data, path="/data", readonly=True),
        SandboxVolume(volume=artifacts, path="/artifacts"),
    ],
    network=False,
)

# ... the agent works in the sandbox ...

Path("population.png").write_bytes(await artifacts.read_file("population.png"))
```


</TabItem>
<TabItem label="Node.js">

```js
const { readFileSync, writeFileSync } = require('node:fs')

const data = await client.createVolume('plot-data')
await data.writeFile('populations.csv', readFileSync('populations.csv'))
const artifacts = await client.createVolume('plot-artifacts')

const sandbox = await client.createSandbox('plot:latest', {
  volumes: [
    { volume: data, path: '/data', readonly: true },
    { volume: artifacts, path: '/artifacts' },
  ],
  network: false,
})

// ... the agent works in the sandbox ...

writeFileSync('population.png', await artifacts.readFile('population.png'))
```


</TabItem>
<TabItem label="Rust">

```rust
use virtx::{Files as _, SandboxCreateArgs};

let data = client.create_volume(Some("plot-data")).await?;
data.write_file("populations.csv", std::fs::read("populations.csv")?, None).await?;
let artifacts = client.create_volume(Some("plot-artifacts")).await?;

let args = SandboxCreateArgs::new("plot:latest")
    .readonly_volume(data.name(), "/data")
    .volume(artifacts.name(), "/artifacts")
    .network(false);
let sandbox = client.create_sandbox(&args).await?;

// ... the agent works in the sandbox ...

std::fs::write("population.png", artifacts.read_file("population.png", 0, None).await?)?;
```

Besides `read_file` and `write_file`, a volume, a sandbox and a snapshot each have `read_dir`, `create_dir_all`, `remove_file` and the rest of a file system's calls (`readDir`, `createDirAll`, `removeFile` in Node.js). The examples under [`examples/`](https://github.com/brekkylab/ailoy/tree/main/examples) copy a whole folder onto a volume before a run and back after it.

For more information, see the [virtx README](https://github.com/brekkylab/virtx).
